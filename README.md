## Guided project: restaurant website

A multi-page, responsive site for *David Chu's China Bistro*, built step by step alongside the course: a home page, menu categories and single-category pages with Bootstrap, custom fonts and jQuery.

[See my version](<https://tarekferdous.github.io/Coursera_html_css_javascript/week3%20(Project)%20-%20Restaurant%20Website/index.html>) · [The real restaurant](https://www.davidchuschinabistro.com/)

## Lecture exercises

| Folder | Topics |
|---|---|
| [`site/week1`](site/week1) | HTML document structure, entities, lists, internal and external links, images |
| [`week2`](week2) | CSS syntax, selectors (element, class, child, descendant, pseudo), specificity, inheritance, text styling, box model, responsive design and media queries, introduction to Bootstrap |
| [`week4`](week4) | JavaScript lecture scripts: avoiding global namespace collisions with IIFEs and namespaced objects |

## Running locally

Everything is static HTML, CSS and JavaScript. Open any `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000    # then open http://localhost:8000
```
